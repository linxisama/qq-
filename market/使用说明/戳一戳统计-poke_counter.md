# 戳一戳统计（poke_counter）

- 版本：5.2.51
- 分类：utility
- 默认启用：否

## 功能

统计每天被戳一戳的次数；被戳时按概率回复预设文本，并对一个数字执行预设运算后播报结果。普通QQ支持真实戳一戳；官方接入用 /戳一戳 指令。/戳一戳统计 查询次数；回复不经模型。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `replyProbability` | 回复概率 | float | `0.3` | 头像戳一戳：0~1，0.3 = 三成概率回复；指令会直接回复，冷却中仍反馈计数。 |
| `cooldownMs` | 冷却时间（毫秒） | int | `3000` | 同一会话两次回复的最小间隔，防止连续戳时刷屏。0 = 不冷却。 |
| `replyTexts` | 预设回复文本 | string | `别戳了啦
戳够了没有
今天第 {count} 次了哦
再戳我要生气了 {n}` | 每行一条，被戳时随机抽一条。占位符：{n} = 当前数值，{count} = 今日被戳次数。 |
| `showNumber` | 回复中带上当前数值 | bool | `True` | 文本里已写 {n} 时以它为准；否则在回复末尾自动追加。 |
| `showDailyCount` | 回复中带上今日次数 | bool | `True` | 文本里已写 {count} 时以它为准；否则自动追加。 |
| `expression` | 数字运算表达式 | string | `n + 1` | 每次被戳对当前数值 n 执行的运算，例：n + 1、n * 2 + 1、round(n / 2)。只支持数字、n、四则运算、括号与 abs/round/min/max/floor/ceil/sqrt。 |
| `initialValue` | 初始数值 | float | `0` |  |
| `perGroup` | 按群独立统计 | bool | `False` | 关闭：所有群共用一份计数与数值；开启：每个群各自计数、各自维护数值。 |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
