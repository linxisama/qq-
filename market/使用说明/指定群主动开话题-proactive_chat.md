# 指定群主动开话题（proactive_chat）

- 版本：5.2.51
- 分类：social
- 默认启用：否

## 功能

在指定群聊中，长时间无消息后主动开启话题

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `groups` | 目标群(逗号分隔) | string | `` |  |
| `idleMinutes` | 触发空闲分钟数 | int | `45` |  |
| `activeHours` | 活跃时段(HH:MM-HH:MM) | string | `10:00-23:00` |  |
| `maxPerDayPerGroup` | 每群每日最多次数 | int | `3` |  |
| `minGapMinutes` | 最小间隔(分钟) | int | `60` |  |
| `jitterSec` | 随机抖动(秒) | int | `45` |  |
| `useModel` | 使用AI生成话题 | bool | `True` |  |
| `topics` | 备用话题(分号分隔) | string | `你们今天都干啥了;刚刷到个东西笑死我了;有没有人打游戏缺一个;中午吃什么啊纠结;最近在追什么剧` |  |
| `maxTokens` | 最大token | int | `120` |  |
| `dailyTokenBudget` | 每日token预算 | int | `30000` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
