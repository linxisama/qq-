# 每三次表情（sticker_cadence）

- 版本：5.2.51
- 分类：personality
- 默认启用：否

## 功能

每个会话中，机器人每成功回复N次附带一张真实图库图片。发送失败不计数，已有图片不再追加，避免官方QQ一条回复多图。没有可用图片时只回文字，不伪装成颜文字。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用定期发表情图片 | bool | `False` |  |
| `sendEveryN` | 每成功回复N次附图 | int | `3` |  |
| `skipIfMismatch` | 对不上语境就不发 | bool | `False` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
