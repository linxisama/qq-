# 缓存稳定性（cache_stability）

- 版本：5.2.51
- 分类：utility
- 默认启用：否

## 功能

移植自社区插件 cache-stability。把"每轮都会变"的说明排到系统提示词最后，让发送前缀尽量逐字节相同 —— 服务商按前缀缓存计费，命中部分便宜一个数量级。同时把真实的缓存命中 token 记进运行记录，并在稳定前缀发生变化（改了人设或稳定说明）时提醒你"缓存会重新预热"。关掉它就回到原来的顺序，行为与未安装时一致。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用缓存稳定性 | bool | `False` |  |
| `stableOrder` | 稳定说明在前、易变说明在后 | bool | `True` |  |
| `reportEvery` | 每多少轮记录一次命中率 | int | `None` |  |
| `verbose` | 每次前缀变化都记录 | bool | `False` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
