# 偷表情包与本地收藏（sticker_steal）

- 版本：5.2.51
- 分类：media
- 默认启用：否

## 功能

自动保存实际收到的表情图片，按内容去重，加入机器人自己的图库。支持官方QQ与普通QQ；不会写入或删除你的QQ收藏。默认只收表情/动图及小尺寸图片，不收普通大照片。官方QQ只能收平台实际推送的消息。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用自动收集 | bool | `False` |  |
| `stickerOnly` | 只收表情包和小图 | bool | `True` |  |
| `maxLibrarySize` | 最多收藏张数 | int | `800` |  |
| `maxLibraryMb` | 图库容量上限（MB） | int | `96` |  |
| `blockedSenders` | 不收这些发送者（逗号分隔） | string | `` |  |
| `allowPrivate` | 收集私聊发送的表情 | bool | `True` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
