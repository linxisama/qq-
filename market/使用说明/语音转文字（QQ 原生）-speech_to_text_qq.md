# 语音转文字（QQ 原生）（speech_to_text_qq）

- 版本：5.2.51
- 分类：media
- 默认启用：否

## 功能

通过普通 QQ / OneBot 协议端的 fetch_ptt_text 接口转写语音。默认关闭，是否可用取决于当前协议端；失败时明确说明，不能猜测。官方接入附件自带的转写文字由消息链路直接读取，无需开启本插件。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `budgetMs` | 单条语音预算（毫秒） | int | `8000` | 默认 8000。 |
| `timeoutMs` | 接口超时（毫秒） | int | `5000` | 默认 5000。 |
| `debugLog` | 调试日志 | bool | `False` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
