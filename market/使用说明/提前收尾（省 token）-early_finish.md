# 提前收尾（省 token）（early_finish）

- 版本：5.2.51
- 分类：utility
- 默认启用：否

## 功能

移植自 JS 插件 early-finish。已交付完毕、没有遗留动作的这一轮，不再为可选的锦上添花动作多花一次模型调用：跳过“该不该接话”的判定调用和“让 AI 选表情”的选择调用。有工具失败、结尾是“我去看看”这类预告、或预告要交图却没交时，一律按正常流程走。不碰提示词、不改人设、不拦发言；“试运行”只记日志不真的省。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用提前收尾 | bool | `False` |  |
| `dryRun` | 试运行（只记录，不真的省调用） | bool | `False` |  |
| `skipJudge` | 跳过“该不该接话”的判定调用 | bool | `True` |  |
| `skipAiReaction` | 跳过“让 AI 选表情”的选择调用 | bool | `True` |  |
| `windowSec` | 只对最近多少秒内交付的这一轮生效 | int | `None` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
