# 主动私信（silence_ping）

- 版本：5.2.51
- 分类：social
- 默认启用：否

## 功能

当指定用户长时间不说话时，主动发私信关心

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `targets` | 目标QQ号(逗号分隔) | string | `` |  |
| `targetIdleMinMinutes` | 触发空闲分钟数 | int | `30` |  |
| `cooldownMinutes` | 冷却时间(分钟) | int | `120` |  |
| `wakeRange` | 生效时段偏移范围(分钟, 格式15-30) | string | `15-30` |  |
| `quietRange` | 静默时段(HH:MM-HH:MM) | string | `00:00-07:00` |  |
| `maxPerDay` | 每日最多发送次数 | int | `20` |  |
| `noRepeatWhenUnreplied` | 未回复时不重发 | bool | `True` |  |
| `dryRun` | 试运行(不实际发送) | bool | `False` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
