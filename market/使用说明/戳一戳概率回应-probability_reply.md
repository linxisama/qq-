# 戳一戳概率回应（probability_reply）

- 版本：5.2.51
- 分类：social
- 默认启用：否

## 功能

被戳时按概率决定是否回应、反戳或忽略。（修正说明：原来只靠文本里有没有「戳了戳」判断拍一拍，而本项目传的是语义化的 notice='poke'，导致插件**从不触发**；现在两种形式都认，并且冷却按「谁戳的」计算。）

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `replyPercent` | 回复概率% | int | `60` |  |
| `pokeBackPercent` | 反戳概率% | int | `30` |  |
| `ignorePokes` | 完全忽略戳 | bool | `False` |  |
| `burstEnabled` | 启用连戳检测 | bool | `False` |  |
| `burstCount` | 连戳次数 | int | `5` |  |
| `burstWindowSec` | 连戳窗口(秒) | int | `30` |  |
| `cooldownSec` | 冷却时间(秒) | int | `600` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
