# @群友（按名字）（at_mention）

- 版本：5.2.51
- 分类：message
- 默认启用：否

## 功能

让机器人用名字 @ 群友：它在正文里写「@泡影之梦 你说得对」时，这里把名字认领成真正的 QQ @ 提醒（对方会收到红点），而不是一串没人看得到的普通字符。支持一次 @ 多人。认不出名字就按原样发送，绝不猜——猜错会 @ 到无关的人。（降级说明：群成员名单靠观察最近说过话的人累积，没说过话的人认不出来。）

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用按名字 @ | bool | `False` |  |
| `maxMentions` | 单条消息最多 @ 几人 | int | `5` | 默认 5，防止模型刷屏式 @ 一长串人。 |
| `allowPartialMatch` | 允许前缀匹配 | bool | `True` | 开启时「@泡影」能匹配到群名片为「泡影之梦」的人；关掉只认完全同名。 |
| `debug` | 记录解析日志 | bool | `False` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
