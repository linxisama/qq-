# 定时暖场（icebreaker）

- 版本：5.2.51
- 分类：utility
- 默认启用：否

## 功能

在睡觉时间（默认 23:30~08:00）之外，每隔几小时自动往指定会话发一条符合当前人设的暖场消息；消息由模型现场生成，每个会话各自随机间隔（不会几个群同时被刷）。留空目标时尝试用最近的活跃会话；拿不到活跃数据就必须显式填目标。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用定时暖场 | bool | `False` |  |
| `chats` | 发送目标（逗号分隔） | string | `` | 例如 group_1059300934, private_1410897629。留空 = 尝试自动挑最近活跃的会话。 |
| `maxChatsPerRound` | 每轮最多发几个会话 | int | `3` | 防止一次给太多群发消息显得像广播。默认 3。 |
| `intervalMinHours` | 间隔下限（小时） | float | `2.0` | 每次发完，下次时间在「下限~上限」之间随机取。默认 2。 |
| `intervalMaxHours` | 间隔上限（小时） | float | `6.0` | 默认 6。想更频繁就填小一点，例如 1~3。 |
| `quietStart` | 睡觉时间开始（HH:MM） | string | `23:30` |  |
| `quietEnd` | 睡觉时间结束（HH:MM） | string | `08:00` |  |
| `maxLength` | 单条消息最长多少字 | int | `150` |  |
| `temperature` | 文风随机度 | float | `0.9` | 默认 0.9，让每次暖场不太一样。 |
| `guide` | 暖场风格指导（可选） | string | `` | 留空用默认要求。想定制就写一句，例如“多聊学习考试话题”。 |
| `dryRun` | 演练模式（只生成不发送） | bool | `False` | 打开后消息只写日志与状态，不真正发出去。调试用。 |
| `minIdleMinutes` | 会话安静多久才暖场 | int | `0` | 默认 0（不看）。本项目扩展：避免刚聊完又去刷一句。 |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
