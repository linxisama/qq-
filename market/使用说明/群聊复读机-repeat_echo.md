# 群聊复读机（repeat_echo）

- 版本：5.2.51
- 分类：social
- 默认启用：否

## 功能

当多人说了相同的话时，机器人跟着复读。纯媒体占位（[图片]、[表情:微笑]、[语音]…）不复读 —— 多人发表情包会得到相同占位文本，复读它只是刷屏。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `pairWindowSec` | 配对窗口(秒) | int | `180` |  |
| `maxLen` | 最大长度(0=不限) | int | `0` |  |
| `cooldownSec` | 复读冷却(秒) | int | `90` |  |
| `maxPerWindow` | 窗口内最多复读次数 | int | `4` |  |
| `windowMin` | 统计窗口(分钟) | int | `30` |  |
| `maxPerHour` | 每小时最多复读次数 | int | `15` |  |
| `sameTextBlockMin` | 同一文本复读屏蔽(分钟) | int | `30` |  |
| `onlyWhenIdle` | 只在没人说话时复读 | bool | `False` | 打开后，若最近 windowMin 内有别的消息活动则跳过，避免插话。 |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
