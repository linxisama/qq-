# 群友花费统计（group_cost_report）

- 版本：5.2.51
- 分类：utility
- 默认启用：否

## 功能

移植自社区插件 group-cost-report：群里 @机器人 说「金额统计」（可跟区间：昨天 / 本周 / 上月 / 最近7天 / 9月1日到9月30日 / 全部…），就把这段时间本群的 token 用量按**触发这次运行的人**逐人列出来。规则触发、立即回复，**不经过模型、零消耗**。填了单价（元/百万 token）才折算金额，没填就只报 token。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用花费统计 | bool | `False` |  |
| `triggerWords` | 触发关键词（逗号分隔） | string | `金额统计,花费统计,花费查询,token统计,用量统计,消费统计` |  |
| `allowWithoutAt` | 不需要 @ 也触发（容易误触发） | bool | `False` |  |
| `defaultRange` | 默认统计区间 | select | `today` |  |
| `topN` | 最多列出几人 | int | `8` |  |
| `maxRows` | 单次最多扫描多少条运行记录 | int | `800` |  |
| `footer` | 报告末尾附统计口径 | bool | `True` |  |
| `priceIn` | 输入单价（元/百万 token，0=不折算） | float | `0.0` |  |
| `priceOut` | 输出单价（元/百万 token，0=不折算） | float | `0.0` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
