# 表情包与自定义图库（image_library）

- 版本：5.2.51
- 分类：media
- 默认启用：否

## 功能

上传图片并保存后，用 /表情 标签 发送；聊天模型也可按语境选择已登记图片。官方QQ与普通QQ均支持本机图片及公开链接。空图库不会猜图或复述收到的图片。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `True` |  |
| `library` | 图库 | string | `` | 上传可多选，自动按文件名生成标签；建议改成“开心”“疑惑”等含义明确的标签。图片导入本机，选中发送时通过当前QQ接口上传给QQ。仍可编辑“标签 ／ 路径或链接”。 |
| `separateMessages` | 官方QQ文字和表情图片分开发送 | bool | `True` | 先发文字，再以不同回复序号单独发表情图片。默认开启；图片仍是官方富媒体，不能变成QQ收藏表情样式。 |
| `autoSelect` | 让聊天模型按语境选择图库图片 | bool | `True` |  |
| `asSticker` | 普通QQ按收藏表情样式发送 | bool | `True` | 普通QQ／OneBot接入生效。官方QQ沿用图片富媒体发送。 |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
