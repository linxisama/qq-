# 点名闸门（mention_gate）

- 版本：5.2.51
- 分类：message
- 默认启用：否

## 功能

给机器人加一道点名闸门：① 名单里的群只在被 @ 或戳一戳时才开口（其余消息不调模型）；② 精确到某个群的某个人（名单外的人照常回复）；③ 名单之外的群可以完全不受影响，也可以谁叫都不理。@ 按 QQ 号判定，重名不会误判。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用点名闸门 | bool | `False` |  |
| `group_ids` | ① 整群只在被@时回复 | string | `` | 填群号，多个用逗号隔开，如 123456789, 987654321。留空 = 本项不启用。 |
| `user_rules` | ② 只回指定的人（按群，一行一个） | string | `` | 格式：群号=QQ号，一行一个。例：123456789=10001,10002。本项只认 QQ 号。 |
| `mode` | ③ 名单外群的待遇 | select | `allowlist` | allowlist = 名单之外的群保持你原来的设置；only = 只服务名单里的群。 |
| `prompt_note` | 提示词里也写明本群规则 | bool | `True` | 默认开：受管群会多一句规则说明，免得模型以为自己漏了消息。 |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
