# 表情包制作（NoneBot 适配）（memes）

- 版本：5.2.51
- 分类：media
- 默认启用：否

## 功能

基于你提供的 nonebot-plugin-memes 0.8.1 和 meme-generator 0.2.3，支持300种模板、搜索/详情/预览、图片加字与GIF、本地制作和成功发送统计。群聊先@；图片在本机处理。首次使用有素材的模板会按需下载官方素材。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `True` |  |
| `directKeywords` | 允许直接用模板关键词制作 | bool | `True` |  |
| `defaultTexts` | 未给文字时使用模板默认文字 | bool | `True` |  |
| `downloadResources` | 首次使用时下载模板素材 | bool | `True` | 仅从固定版本的官方仓库下载并校验，不上传用户图片。关闭后只使用已缓存素材。 |
| `disabledTemplates` | 禁用模板（名称或key，逗号分隔） | string | `` |  |
| `cooldownSec` | 同一会话同一人制作间隔（秒） | int | `10` |  |
| `maxImages` | 每次最多输入图片数 | int | `3` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
