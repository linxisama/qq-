# 睡眠时段（sleep_mode）

- 版本：5.2.51
- 分类：rhythm
- 默认启用：否

## 功能

在指定时间段内不回复消息

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `startTime` | 开始时间 | string | `00:00` | 格式 HH:MM |
| `endTime` | 结束时间 | string | `07:00` | 格式 HH:MM |
| `allowAt` | @时仍回复 | bool | `True` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
