# 上下文插话判定（context_chime）

- 版本：5.2.51
- 分类：message
- 默认启用：否

## 功能

用一次极短的模型调用判断「这条消息值不值得主动接话」。⚠️ 机制差异：原版在调模型之前判定，判「不接」= 0 token；本项目只能在 AI 调用前（同步钩子）里用独立事件循环发判定请求，判「不接」是拦住回复，**省不下已经花掉的 token**。判定失败默认按「不接」处理（与原版一致，保守侧）。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `allowPrivate` | 私聊也插入背景 | bool | `False` |  |
| `cooldownSec` | 同群冷却(秒) | int | `12` | 默认 12：不让每条消息都打一次模型。 |
| `minChars` | 短于多少字不判 | int | `4` |  |
| `windowSize` | 判定看最近几条 | int | `14` |  |
| `judgeProbability` | 判定采样概率(%) | float | `100.0` | 默认 100（每条都判）。调低可以省钱。 |
| `dailyCallLimit` | 单群每日判定上限 | int | `400` |  |
| `confidenceThreshold` | 自信度下限 | float | `0.0` | 默认 0。调高会要求模型更有把握才接。 |
| `onlyGroups` | 仅限群(逗号分隔,空=全部) | string | `` |  |
| `denyGroups` | 排除群(逗号分隔) | string | `` |  |
| `judgeModel` | 判定专用模型 | string | `` | 留空 = 沿用聊天主模型。建议用能关思考的小模型，否则 reasoning 会吃光输出预算。 |
| `maxTokens` | 判定输出上限(token) | int | `64` |  |
| `timeoutMs` | 判定超时(毫秒) | int | `6000` |  |
| `promptExtra` | 追加判据 | string | `` |  |
| `blockOnJudgeFailure` | 判定失败就不接 | bool | `True` | 默认开，与原版一致（宁可少接，不可乱接）。关掉则失败时照常回复。 |
| `blockOnTimeout` | 判定超时也不接 | bool | `False` | 默认关：判定模型慢的时候仍然让机器人可用。需要和原版完全一致就打开。 |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
