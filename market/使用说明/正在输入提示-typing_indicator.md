# 正在输入提示（typing_indicator）

- 版本：5.2.51
- 分类：utility
- 默认启用：否

## 功能

私聊（可选群聊）里让机器人像真人一样亮起「正在输入…」：从它决定要回话到消息发出之间，对方会看到正在输入。零 token：不改提示词、不注册工具、不调模型，只在对的时机补发状态包。（需要协议端支持 set_input_status；官方接口不支持，此模式下不生效。）

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `showTyping` | 显示输入提示 | bool | `True` | 关掉后不再发状态包（与原开关语义一致）。 |
| `privateOnly` | 只在私聊生效 | bool | `True` | 默认开。群聊里「正在输入」观感因协议端而异，需要就关掉这项。 |
| `eventType` | 状态类型 | select | `typing` | typing = 正在输入（默认）；speaking = 正在讲话（录音中）。 |
| `cooldownSec` | 同一会话冷却（秒） | int | `5` | 默认 5：短时间内连续回复时不重复发状态包。 |
| `minDelayMs` | 预计很快回时不发（毫秒） | int | `0` | 默认 0（总是发）。填 800 这类值可以避免「秒回」时闪一下正在输入；判定依据是上一条消息距今的时间（消息来得太密时就不发状态）。 |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
