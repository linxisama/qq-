# 群友好感度（affinity）

- 版本：5.2.51
- 分类：social
- 默认启用：否

## 功能

移植自社区插件 affinity：自动给每个群友累积好感度 —— 发言加分、@机器人加分、接话加分，每人每天有上限防刷屏；长期不发言缓慢衰减；主人恒为满级。等级：陌生/眼熟/熟人/老友/挚友。当前说话人的真实分数与等级会作为"易变说明"注入提示词，问到"你我多熟"时不会编数字。口令：好感度 / 好感度 排行 [N] / 好感度 重置 [QQ号]（主人）/ 好感度 设置 <键>=<值>（主人），全部零消耗。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用好感度 | bool | `False` |  |
| `perMessage` | 每条发言加分 | int | `1` |  |
| `atBotBonus` | @机器人额外加分 | int | `3` |  |
| `replyBonus` | 接话额外加分 | int | `2` |  |
| `dailyCap` | 每人每天加分上限 | int | `20` |  |
| `decayAfterDays` | 多少天不发言开始衰减 | int | `7` |  |
| `decayPerDay` | 每天衰减多少分 | int | `1` |  |
| `replyWindowSec` | 多久内算"接话"（秒） | int | `90` |  |
| `scanLimit` | 每次补扫的聊天记录条数 | int | `200` |  |
| `backfillSeconds` | 同一会话最短多久补扫一次（秒） | int | `30` |  |
| `topN` | 排行榜默认人数 | int | `10` |  |
| `announceLevelUp` | 升级时让她顺口提一句 | bool | `True` |  |
| `allowReset` | 允许任何人重置好感度 | bool | `False` |  |
| `ownerQq` | 主人 QQ 号（逗号分隔；留空=沿用机器人管理里绑定的管理员） | string | `` |  |
| `ownerScore` | 主人显示的固定分数 | int | `9999` |  |
| `levelThresholds` | 等级门槛（4 个递增数字，逗号分隔） | string | `50,200,500,1000` |  |
| `verbose` | 在控制台记录每次加分 | bool | `False` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
