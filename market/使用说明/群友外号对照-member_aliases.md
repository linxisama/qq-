# 群友外号对照（member_aliases）

- 版本：5.2.51
- 分类：knowledge
- 默认启用：否

## 功能

移植自社区插件 member-aliases：谁在说话就告诉模型这人还叫什么；消息里出现某人的外号时，告诉模型指的是谁 —— 命中才加几行，没命中一个字不加。外号表可用口令维护：外号 / 外号 加 <QQ号> <外号> / 外号 删 <QQ号> <外号>（管理员或主人）；可选自动从"我叫X"里学（默认关）。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用外号对照 | bool | `False` |  |
| `scanMentions` | 识别「别人提到外号」 | bool | `True` |  |
| `maxLines` | 每轮最多几行 | int | `12` |  |
| `autoLearn` | 自动记下"我叫X"（默认关） | bool | `False` |  |
| `verbose` | 在控制台记录加了哪几行 | bool | `False` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
