# 对话完成判定（turn_complete）

- 版本：5.2.51
- 分类：message
- 默认启用：否

## 功能

同一个人连着发消息时，别在人家话还没说完的时候插嘴。按内容判定：结尾悬着、落在连接词上、或者只有几个字 → 再多等一会儿；像一句问话、只是在喊人、说得比较长 → 照常回。（移植说明：JS 版靠宿主的唤醒倒计时仲裁，本项目只在当前一轮内延后等待，不会提前回复；多人同时说话时把说话人摘要告诉模型。）

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `contentJudge` | 按内容判定 | bool | `True` | 关掉后只按节奏（消息间隔）判定，不分析文字内容。 |
| `quietMs` | 没说完再等(毫秒) | int | `6000` | 判定为“还没说完”时，把这一轮往后推这么久。 |
| `capMs` | 一轮最多等(毫秒) | int | `20000` | 封顶：对方一直发、一直没说完，也不会一直不吭声。0 = 完全不等待。 |
| `anchorOnly` | 只认先开口的人 | bool | `True` | 开启时，群里别人插话不会被算进他这一轮。 |
| `tellModel` | 把说话人告诉模型 | bool | `True` | 多人同时说话时，把“谁在说、各说了几条”写进提示词。 |
| `maxDelayMs` | 单轮延迟上限(毫秒) | int | `8000` | 本项目安全阀：无论判定结果如何，单轮延后不超过这个值。 |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
