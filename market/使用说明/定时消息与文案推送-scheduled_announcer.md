# 定时消息与文案推送（scheduled_announcer）

- 版本：5.2.51
- 分类：social
- 默认启用：否

## 功能

在指定星期和时刻给指定群发送固定文字，或用现有模型生成文案。普通QQ接入可用；官方QQ的主动消息权限不在本功能支持范围内。每次任务独立去重，超时发送不会自动重发。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `weekdays` | 星期（1=周一，7=周日，逗号分隔） | string | `1,2,3,4,5,6,7` |  |
| `times` | 时刻（HH:MM，逗号分隔） | string | `08:30` |  |
| `groupIds` | 目标群号（逗号分隔） | string | `` |  |
| `content` | 发送内容或文案主题 | string | `早上好，今天也要照顾好自己。` |  |
| `useAI` | 按主题调用现有模型生成文案 | bool | `False` |  |
| `maxChars` | 文案字数上限 | int | `220` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
