# 表情包库上限（sticker_cap）

- 版本：5.2.51
- 分类：media
- 默认启用：否

## 功能

防止有人一直发表情包把库和磁盘撑爆：按数量上限做 LRU 淘汰、按磁盘配额清理、可屏蔽指定人的表情。只管理机器人实际收藏的表情库和索引，不删除外部目录或手动图库；收集由“偷表情包”插件完成，/表情容量 可查看用量。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `stickerDir` | 表情库目录 | string | `None` | 兼容旧配置；当前运行时固定管理 data/sticker_library，只会清理索引登记的收藏图片。 |
| `maxItems` | 最多存多少个 | int | `None` | 0 = 不限制。超过后按最久未用淘汰。 |
| `maxSizeMb` | 磁盘配额（MB） | int | `None` | 0 = 不限制。超过后按最久未用删除，直到降到配额以内。 |
| `blockedSenders` | 不收这些人的表情 | string | `` | 逗号分隔 QQ 号。 |
| `dryRun` | 只统计不删除 | bool | `True` | 默认开（安全）：先看看会删多少，确认后再关掉真正执行。 |
| `checkIntervalSec` | 检查间隔（秒） | int | `3600` | 默认 3600。 |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
