# 回复时机与引用（reply_freshness）

- 版本：5.2.51
- 分类：social
- 默认启用：否

## 功能

移植自社区插件 reply-freshness：把"现在几点、群里最新一条是谁、你要回的那条还新不新鲜"算清楚，追加在当前这条消息末尾（不动系统提示词，不伤前缀缓存）。晚回就自然补一句衔接；群里冷场时提醒她别为了清空未读继续回旧消息。另有可选的硬刹车「冷场就不回」（默认关）：真的安静下来又没人点她时，本轮不发。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用回复时机提示 | bool | `False` |  |
| `quietSeconds` | 安静多少秒算冷场 | int | `90` |  |
| `lateReplySeconds` | 超过多少秒算晚回 | int | `45` |  |
| `coldAdvice` | 冷场时提醒"别硬接" | bool | `True` |  |
| `coldHold` | 冷场且没人点她时干脆不回（默认关） | bool | `False` |  |
| `announce` | 注入时序说明 | bool | `True` |  |
| `scanLimit` | 回看多少条记录算时序 | int | `40` |  |
| `verbose` | 在控制台记录时序判断 | bool | `False` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
