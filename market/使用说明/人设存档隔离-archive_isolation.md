# 人设存档隔离（archive_isolation）

- 版本：5.2.51
- 分类：utility
- 默认启用：否

## 功能

切换人设后分开对话历史与个人记忆，再切回来可继续原有存档；不会删除或搬走用户文件。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `True` |  |
| `protectKeys` | 共用记忆的会话（group:ID 或 private:ID，逗号分隔） | string | `` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
