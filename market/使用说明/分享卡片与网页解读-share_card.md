# 分享卡片与网页解读（share_card）

- 版本：5.2.51
- 分类：media
- 默认启用：否

## 功能

把群友转发的分享卡片与链接整理进上下文：卡片自带的标题/描述/来源/跳转链接会被解析出来，并标出平台（B站、抖音、小红书…），同一链接 10 分钟内只整理一次。可选读取公开网页标题、描述和正文；遇登录/验证码/动态网页会明确说明。截图识别使用现有视觉插件。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `readWeb` | 读取公开网页正文 | bool | `False` | 只读取公开链接，不登录，不执行网页脚本；会向该网站请求页面。 |
| `readCards` | 解析分享卡片 | bool | `True` | 从卡片自带的元数据取标题/描述/来源，不需联网。 |
| `collectLinks` | 收集正文里的链接 | bool | `True` | 把消息里的链接一并整理进上下文。 |
| `maxLinks` | 每条消息最多几个链接 | int | `3` |  |
| `cacheTtlSec` | 同一链接的整理间隔（秒） | int | `None` | 默认 600。避免同一条链接反复塞进上下文。 |
| `readTimeoutMs` | 单个网页读取超时（毫秒） | int | `3000` | 默认 3000。读取正文是**在回复之前**做的：设太大时，一条带链接的消息会让回复一直等网页。超时就按“没读到”继续回答。 |
| `readBudgetMs` | 整条消息读网页的总预算（毫秒） | int | `4000` | 默认 4000。多个链接**并发**读取，且总耗时不超过这个预算，避免一条消息把回复拖成十几秒。 |
| `platformHint` | 标出平台 | bool | `True` | 例如把 bilibili.com 标成 B站。 |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
