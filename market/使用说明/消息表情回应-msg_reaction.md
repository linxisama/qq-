# 消息表情回应（msg_reaction）

- 版本：5.2.51
- 分类：social
- 默认启用：否

## 功能

普通QQ群聊专用：/贴表情 128077 或“给我点个赞”可给消息气泡贴反应；可按概率自动贴，支持AI选表情及随机模式、冷却和小时/每日上限。官方QQ群聊当前不执行此动作，会明确说明。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用消息表情回应 | bool | `False` |  |
| `mode` | 自动表情选择 | select | `random` |  |
| `target` | 自动贴到哪条消息 | select | `replied` |  |
| `probabilityPercent` | 自动贴表情概率（%） | int | `20` |  |
| `minGapSec` | 自动动作冷却（秒） | int | `300` |  |
| `maxPerHour` | 每小时最多自动次数 | int | `3` |  |
| `maxPerDay` | 每天最多自动次数 | int | `15` |  |
| `emojiIds` | 可选表情编号（逗号分隔） | string | `128077,128514,129300` |  |
| `delaySec` | 自动动作延迟（秒） | int | `3` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
