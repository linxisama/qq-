# 极简模式（省 token）（minimal_mode）

- 版本：5.2.51
- 分类：utility
- 默认启用：否

## 功能

移植自社区插件 minimal-mode。按档位砍掉每轮都要重发的聊天记录、给输出封顶、并追加一小段"说短话"的纪律：极简 / 极限 / 敢死三档，越往后越省、越不像人。管理员私聊发「/极简 开 / 关 / 极限 / 敢死」即可切换（不经过模型，零消耗），「/极简」看状态。关掉立刻恢复原样。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用极简模式插件 | bool | `False` |  |
| `tier` | 当前档位 | select | `off` |  |
| `ownerIds` | 允许开关口令的管理员（留空=沿用机器人管理里绑定的管理员） | string | `` |  |
| `minimalMsgs` | 极简档保留的历史消息条数 | int | `12` |  |
| `ultraMsgs` | 极限/敢死档保留的历史消息条数 | int | `6` |  |
| `minimalMaxTokens` | 极简档输出上限（0=不限） | int | `0` |  |
| `ultraMaxTokens` | 极限档输出上限 | int | `300` |  |
| `kamikazeMaxTokens` | 敢死档输出上限 | int | `80` |  |
| `verbose` | 在控制台记录每次省下的内容 | bool | `True` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
