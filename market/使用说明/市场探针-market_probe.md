# 市场探针（market_probe）

- 版本：5.2.51
- 分类：utility
- 默认启用：否

## 功能

抓取插件市场目录并按关键词筛出相关插件，结果只展示、不自动安装。默认指向 QQ Agent 社区市场（kondius.cn/api/community/plugins），清单里会标出哪些本项目已经移植过、哪些评估过但不适用；也支持通用 JSON 目录（{"plugins":[{name,url,description,tags}]}）与常见 HTML 目录页。管理员在 QQ 私聊里发“市场 [关键词]”，或在管理员模式下直接发“市场”。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用市场探针 | bool | `False` |  |
| `marketUrl` | 市场目录地址（http/https） | string | `None` |  |
| `keywords` | 默认关键词（逗号分隔，留空=全部） | string | `None` |  |
| `maxItems` | 最多展示条数 | int | `8` |  |
| `timeoutSec` | 抓取超时（秒） | int | `15` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
