# 好感度主动开话题（affinity_proactive）

- 版本：5.2.51
- 分类：utility
- 默认启用：否

## 功能

按好感度等级排期，到点时按等级概率主动开一句（越高越自然、越不靠频率）。（降级说明：本项目没有好感度技能存档，分数请在「好感度分数」里显式填写；发送走宿主队列并留档；未回复时不继续追问；拿不到未读计数，只能按上次发言时间判断。）

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `False` |  |
| `affinityScores` | 好感度分数 | string | `` | 形如 group:123=95,private:456=140；键必须写成 group:数字 或 private:数字。 |
| `scanIntervalSec` | 扫描间隔（秒） | int | `60` | 默认 60。tick 每约 60 秒跑一次，这里只做下限保护。 |
| `quietStartHour` | 静默开始（小时） | int | `0` |  |
| `quietEndHour` | 静默结束（小时） | int | `8` |  |
| `idleMinMs` | 距上次互动多久才主动（毫秒） | int | `600000` | 默认 600000（10 分钟）。 |
| `maxTokens` | 生成上限（token） | int | `160` |  |
| `allowList` | 只对这些会话主动 | string | `` | 逗号分隔；可写 group:123 或只写 123。留空且 deny 也空时，需要开「空名单时放行」。 |
| `denyList` | 不对这些会话主动 | string | `` | 优先级高于 allow。 |
| `allowAllWhenEmpty` | 空名单时放行 | bool | `False` |  |
| `guide` | 额外风格要求 | string | `` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
