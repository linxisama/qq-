# 跨会话认人（cross_chat_link）

- 版本：5.2.51
- 分类：social
- 默认启用：否

## 功能

同一稳定用户标识的已确认偏好可用于其他会话；默认禁止把私聊记忆带入群聊。官方 QQ 不同场景标识不一致时不会猜测身份。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `True` |  |
| `privateToGroup` | 允许将私聊偏好用于群聊 | bool | `False` |  |
| `maxImpressions` | 最多引用偏好数 | int | `3` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
