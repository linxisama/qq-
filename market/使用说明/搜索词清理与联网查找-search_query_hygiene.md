# 搜索词清理与联网查找（search_query_hygiene）

- 版本：5.2.51
- 分类：utility
- 默认启用：否

## 功能

发送 /搜索 关键词，清理口语后读取必应结果并提供带链接的参考；搜索失败明确说明，不编造来源。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `True` |  |
| `maxResults` | 最多结果数 | int | `5` |  |
| `timeoutMs` | 搜索超时（毫秒） | int | `6000` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
