# 鲸鱼娘情绪与精力（emotion_state）

- 版本：5.2.51
- 分类：social
- 默认启用：否

## 功能

维护角色的心情、精力和压力，随时间恢复；只在消息发送成功后更新。/状态 可查看当前角色状态。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | bool | `True` |  |
| `injectPrompt` | 把角色状态用于回复语气 | bool | `True` |  |
| `autoUpdate` | 根据互动更新状态 | bool | `True` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
