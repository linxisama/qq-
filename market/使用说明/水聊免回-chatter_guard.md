# 水聊免回（chatter_guard）

- 版本：5.2.51
- 分类：message
- 默认启用：否

## 功能

连着发表情包、或者一直说水话的时候，机器人就不接了（连模型都不叫醒，0 token）。只认三类明确的水：纯表情/图片、命中水词表（哈哈、草、6、。。。、笑死…）、同一个字重复或全是标点。**不用「字数太少」当判据**——那会误伤「在吗」「谢谢」「几点」。中间插一句正常话就重新计数。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用（连续水聊就免回） | bool | `False` |  |
| `threshold` | 连着几条就不回 | int | `3` | 默认 3，第 3 条起不再接话。设成 1 会变成「只要发水话就不理」，太容易误伤。 |
| `windowSec` | 多久之内算「连着」 | int | `180` | 默认 180（3 分钟）。超过这个间隔就重新计数。 |
| `skipMedia` | 纯表情包/图片算水 | bool | `True` |  |
| `skipFiller` | 纯水话算水 | bool | `True` |  |
| `fillerWords` | 自己补充的水词 | string | `` | 逗号分隔，会加到内置水词表里。误伤了就往这里删或关掉「纯水话算水」。 |
| `alwaysReplyWhenAtMe` | @ 它时仍然回 | bool | `False` | 默认关。开着的话，哪怕对方在刷表情包，只要 @ 了它就照常接。 |
| `exemptKeyword` | 豁免关键词 | string | `` | 正文含这个词的消息一律照常回复（本项目额外提供，JS 版没有）。 |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
