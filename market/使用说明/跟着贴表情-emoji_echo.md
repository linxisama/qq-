# 跟着贴表情（emoji_echo）

- 版本：5.2.51
- 分类：social
- 默认启用：否

## 功能

普通QQ/OneBot专用：群友给消息贴表情回应时，跟贴同一条消息的同一个表情，全程不调用模型、不发文字。当前官方QQ群聊接入不支持此动作，会保持不执行；图片表情不受影响。

## 安装

1. 打开鲸鱼娘 QQ 控制台 →「插件中心」；
2. 点「添加插件」→「浏览…」，选择本压缩包；
3. 点「检查」，确认名称、说明与安全检查通过；
4. 勾选「覆盖同名插件」（更新时）和「安装后立即启用」；
5. 点「确认安装」。

安装后可在插件列表里调整参数；不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用跟贴 | bool | `False` |  |
| `delayMs` | 跟贴延迟（毫秒） | int | `900` |  |
| `minIntervalMs` | 最小间隔（毫秒） | int | `1500` |  |
| `maxPerMinute` | 每分钟最多次数 | int | `20` |  |
| `groupWhitelist` | 只在这些群生效（逗号分隔） | string | `` |  |
| `emojiBlacklist` | 不跟贴的表情编号（逗号分隔） | string | `` |  |
| `followRemove` | 跟随取消表情 | bool | `False` |  |

## 注意

- 插件是外部代码，安装后会被加载执行，请只使用可信来源；
- 依赖外部服务的插件（搜索、图片站、语音等）需要相应网络或本机组件；
- 与聊天主链路无关的插件默认关闭，按需开启。
