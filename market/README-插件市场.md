# QQ 插件市场

鲸鱼娘 · QQ 控制台的第三方插件包，共 **42 个**。
每个包都是「单文件插件包」：一个 zip，解压只有 `plugin.json`、`<id>.py`、`使用说明.md` 三个文件，不含依赖、不需要编译。

## 怎么装

前提：已经装好并跑起来鲸鱼娘 QQ 控制台（本目录只是插件包，不是控制台本体）。

1. 打开控制台 ->「插件中心」->「添加插件」；
2. 在「本地文件」里选中 `packages/` 下的某个 zip；
3. 先点「检查」，看清名称、说明与安全检查结果；
4. 点「确认安装」（同名插件升级时勾选「覆盖」）；
5. 回到插件页手动启用，并按需调参数。

装完的插件落在控制台数据目录的 `custom_plugins/` 下，并登记进 `custom_plugins.json`；卸载直接在插件页删，不用回来找本目录。

## 目录结构

```
index.json         机器可读索引（id / 版本 / 分类 / 文件名 / sha256 / 字节数）
packages/          42 个可直接安装的 zip
使用说明/          每个插件一页，不解压也能看
tools/             校验脚本（普通用户用不到，见文末）
```

## 说明

- 这 42 个包全部用控制台真实安装器逐包验收过：inspect_local 预检 -> install_from_file -> finish_install -> 新建 PluginManager 重启后仍在插件表内。
- 控制台安装包里内置的 21 个基础插件不在这里，它们随控制台一起装好，无需另装。
- 外部服务类插件（Pixiv、热梗、图片理解等）需要自己填 API 或地址，装好默认不启用，不会自己往外发请求。
- 插件代码来源于鲸鱼娘 QQ 控制台 5.2.51 版本的 src/plugins，逐包附 使用说明.md。

## 校验（可选）

装之前想自己复核一遍，用本目录的校验脚本，它走的是控制台真实安装链路：

```bash
python tools/verify_market.py --console <控制台源码根>
```

`--console` 指向含 `src/plugin_installer.py` 的目录。脚本会对每个包做 sha256 比对、包内成员核对、
`inspect_local` 预检、真实安装、新建 `PluginManager` 重启确认，全部 PASS 才返回 0。
受限环境下系统临时目录不可写时，加 `--work <可写目录>`。
