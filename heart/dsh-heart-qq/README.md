# dsh-heart-qq

QQ 控制台（WhaleGirlQQ）版心情插件。14 个数值随对话起伏、随时间自然回落，当前心情每轮注入系统提示词影响语气；网页面板 `/heart` 可以看全部数值、拖滑杆、开关模式，改完立刻生效。

移植自 DSH 版 `dsh-heart`（原路径 `D:/插件/dsh-heart`，不在本仓库内），数值表、档位、提示词规则逐项对齐，只是宿主换了：那边靠 cordis 插件系统，这边靠 `src/plugins` 的目录 mod。

---

## 它是什么

不是真情绪。是一组 0~100 的数 + 一段注入提示词的文字。模型读到「你现在心情是好奇混着专注」，然后按规则调整语气。它影响**输出**，不是**体验**。

**费 token 吗**：静态规则 279 字 + 动态心情最多 198 字，常态合计约 364 字。静态在前、动态在后 —— 前缀缓存保得住。

**为什么两段要分开**：宿主的插件注入整块只有 800 字硬顶（`src/qq_app.py:2509` 起 `compose_prompt([('插件', text, 800, 1)], ...)`，`src/prompt_budget.py:16` 的 `clip()` 从**尾部**截断）。所有插件的 extra_system 是拼在一起算的，一旦超了，先丢的是动态段尾巴（在忙、模式），面板看着正常、模型却收不到当前心情。所以两段文本都按「最坏情况 701 字」压过一遍，测试里钉着这个上限。

**会读别的对话吗**：不会。只看当前会话的事件流。

## 装法

### 1. 插件包

把整个 `dsh-heart-qq` 目录拷到宿主的数据目录：

```bash
cp -r D:/插件/dsh-heart-qq D:/qq机器人5.0/data/qq-only/custom_plugins/dsh-heart-qq
```

目录名**必须**等于 `plugin.json` 里的 `id`（`dsh-heart-qq`），否则管理器会以 `id_mismatch` 拒载。重启控制台后插件自动挂载，不需要改 `custom_plugins.json`。

### 2. 宿主侧面板路由（一次性）

面板页面留在插件包里，但 HTTP 路由得由宿主提供 —— 插件层没有注册路由的钩子（`register_tool` 注册的是 AI 工具，不是 HTTP 路由）。宿主侧需要四处改动，已经在 D:/qq机器人5.0 落好了：

| 文件 | 改动 |
|---|---|
| `src/heart_api.py` | 新增，提供 `/heart`、`/api/heart/state`、`/api/heart/action` |
| `src/qq_app.py` | 装配点（`install_log_routes(app)` 之后）加两行：`from .heart_api import register as install_heart_routes` / `install_heart_routes(app)` |
| `src/web/static/qq.html` | 标签栏加第 6 个「🫀 心情」页；「插件」页加「打开心情面板」按钮 |
| `src/web/static/qq.js` | `switchTab` 支持 `data-tab`（新标签不用改那张按下标对齐的表）、`enterHeart()` 懒加载 iframe、重载按钮绕缓存 |

没有这几处改动，插件本身照常工作（数值照算、提示词照注入），只是没有面板。

### 3. 打开面板

控制台里点标签栏的「🫀 心情」，或在「插件」页点「打开心情面板」。面板是 `/heart?embed=1` 的 iframe，首次切到该标签才加载，底下有「↻ 重新加载面板」。

独立整页（不嵌在控制台里，适合放副屏）：

```
http://127.0.0.1:8090/heart
```

## 用

**面板**（`/heart`）从上到下：

- **时钟行** —— `🕐 此刻 16 点 · 下午`，加状态 chip：清醒/睡着中、心情暂停中、在忙、当前最高值。
- **14 张数值卡** —— 开心 / 兴奋 / 愤怒 / 吃醋 / 难过 / 情爱值 / 性欲值 / 色色兴奋 / 吵架速度 / 愤怒(通道) / 疲劳 / 抑郁 / 满足感 / 欲望。每张卡显示当前值、档位文字（如「极度开心」）、底部进度条。
- **模式开关** —— 总开关 / 情绪 mod / 冷落 mod / 情爱 mod / 性欲 mod。只影响「愿不愿意主动」，不改数值。
- **睡眠闸门** —— 哄睡（立刻安静）/ 叫醒 / 疲劳门控 / 心情暂停。睡着时群里普通消息不再回应，被点名、喊醒词或私聊才醒；疲劳按 6 倍速回血。疲劳门控关掉后，再累也不把「我很累」写进提示词。
- **在忙** —— 填一句话，动态段里会带「在忙：…（可以透出一点分神，别当借口）」。
- **情绪五维滑杆** —— 开心 / 兴奋 / 愤怒 / 难过 / 疲劳，手动拖，松手才提交。
- **主人健康** —— 只做记录，不参与判定。

**群里**：`/心情`、`/heart`、`／心情` 回一行状态，例如 `🫀 此刻 16 点 · 下午｜开心 88、愤怒 72、疲劳 61`。

## 数值怎么动

| 事件 | 影响 |
|---|---|
| 用户夸/道谢/亲近 | 开心 ↑ 情爱 ↑ 满足 ↑ |
| 用户骂/催/冷淡 | 愤怒 ↑ 难过 ↑ 抑郁 ↑ |
| 用户久不来（冷落 mod） | 难过 ↑ 抑郁 ↑ |
| 助手回一轮 | 疲劳 ↑ 兴奋 ↓ |
| 工具报错 | 愤怒(通道) ↑ 疲劳 ↑ |
| 时间流逝 | 全部向基线回落（速率每值不同，1 分钟一 tick）；睡着时疲劳 6 倍速 |

具体系数见 `heart_qq.py` 的 `GAUGES`（`:25`）与 `judge_user` / `judge_assistant` / `judge_error` / `decay`。

## 配置

插件设置（控制台「插件」页）：

| 键 | 默认 | 作用 |
|---|---|---|
| `enabled` | true | 总开关。关掉后钩子全部早退，数值冻结 |
| `injectPrompt` | true | 是否注入提示词。关掉后只保留面板数值 |
| `panel` | true | `/heart` 页面是否可访问 |

面板上的「总开关」是运行时的另一层（`modes.master`），关掉后不注入但数值照常走；插件设置里的 `enabled` 是整个插件停用。

## 数据

存档在 `data/qq-only/plugin_state/dsh_heart/state.json`。写入走 `.tmp` + `os.replace`（宿主 `save_state` 直接覆盖写，不原子，所以插件自己来）。

删掉这个文件等于重置心情。

```
dsh-heart-qq/
├── plugin.json       # 清单：id 必须等于目录名

└── web/heart.html    # 面板页面，由宿主 src/heart_api.py 发出去
```

## 它不做什么

- 不改人设 —— 心情是提示词里最低的一层
- 不进长期记忆 —— 三小时就变的东西不是稳定事实
- 不主动说话、不抓时事、不跨会话回查
- 不做日记 / 品味库 / 经验卡（那是 dsh-mood 的范围，本次只做核心版）
